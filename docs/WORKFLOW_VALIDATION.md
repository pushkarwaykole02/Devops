# Request Submission Validation Rules

- Contact Name: Non-blank, max 100 characters
- Mobile Phone: Exactly 10 numeric digits
- Email: Valid standard email format
- Address Line 1: Street / Building identifier
- Postal Code: 5 to 6 digits
- Preferred Date: Must be present and not in the past
- Supporting Documents: PDF, PNG, JPG, JPEG, DOCX (<= 10MB)
